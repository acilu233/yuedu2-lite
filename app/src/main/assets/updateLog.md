更新日志

1.1

* 阅读菜单整块从屏幕底部搬到左右两条竖列：左侧是 目录 / 调节 / 自动翻页 / 上一章，
  右侧是 界面 / 设置 / 夜间模式 / 下一章；底部不再占用正文，菜单只浮在正文上层，
  开关菜单依旧不会让正文重新排版
* 菜单按钮统一加上底板与描边：白天近黑描边、夜间白色描边，夜间相邻按钮之间有清晰的白色分隔
* 阅读进度条移除；「替换净化」移入右上角菜单，新增「替换规则」入口，原「替换净化」开关保留
* 侧边栏「下载任务」改为「缓存管理」：只显示已经缓存过章节的书，展示「已缓存 N/M 章」进度，
  可以对该书 继续缓存 / 停止缓存，顶部菜单可以「全部停止」
* 修复 Fire OS / Android 4.4 安装时「应用包访问权限帮助程序已停止」的崩溃
  （系统的安装服务解析不了带 v2 签名的包），为此额外提供只签 v1 的安装包：阅读Lite-1.1-Kindle.apk
* 修复阅读菜单最后一行被系统导航栏挡住、按钮几乎看不见的问题（菜单改到两侧后不再受导航栏影响）

1.0（首个发布版本）

* 基于「阅读 2.0」（MyBookshelf）精简改造，安装包约 10MB
* 移除全部广告、付费门禁、捐赠入口与公众号/群推广内容
* 支持 3.0 格式书源，内置番茄书源
* 新增番茄直达：搜索页菜单可直接粘贴分享链接/文案/书号
* 适配 Android 4.4：修复老系统 TLS 1.2 握手失败、适配沉浸式全屏
* 启动优化：冷启动约 2~3 秒，书源与书籍信息改为后台线程加载
* 墨水屏适配：只保留黑白两套配色，去掉界面动画、翻页动画和列表切换动画
* 阅读页固定：调出菜单时系统栏只是覆盖内容，正文不再重新排版
* 彻底移除朗读（TTS 服务、朗读按钮、朗读定时、朗读语速）与有声书、WebDAV、Web 服务、扫码、Wi-Fi 传书等无用模块
* 阅读菜单底部按钮精简为三个（自动翻页、替换规则、夜间）并居中
* 缓存改为只能手动清理，不再自动删除
* 使用独立签名发布，包名 com.acilu233.yuedulite，可与原版共存
