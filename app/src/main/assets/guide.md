使用说明

一、第一次使用
1. 先确认书源：侧边栏 → 书源管理，书源要处于启用状态（本版内置了番茄书源）。
2. 找书：书架页的搜索按钮 → 输入书名 → 在结果里挑一个来源 → 加入书架。
3. 本地书：书架页侧边栏 → 添加本地，可导入手机里的 txt 文件。

二、番茄直达（内置）
1. 搜索页右上角菜单 → 番茄直达。
2. 粘贴番茄小说的分享链接、分享文案或书籍 ID，也可以直接按书名搜；选中后加入书架即可阅读。
3. 番茄接口是官方私有接口，随时可能被改动。失效时请等新版本，或改用其他书源。

三、阅读操作
1. 点屏幕中间：调出阅读菜单。菜单在屏幕左右两侧：
   左侧从上到下是 目录、调节、自动翻页、上一章；右侧从上到下是 界面、设置、夜间模式、下一章。
2. 点屏幕左/右两侧的空白处：翻页。也可以在「更多设置」里开启音量键翻页。
3. 长按正文：划线、复制、搜索、替换。
4. 右侧「界面」：字体、字号、行距、段距、左右边距、全屏等。
5. 右侧「设置」：翻页方式、自动翻页、屏幕常亮、缓存、备份等。
6. 右侧「替换净化」相关的规则管理在顶部菜单 → 替换规则。
7. 菜单只是浮在正文上层，开关菜单不会让正文重新排版。

四、缓存（注意）
1. 本版取消了自动清理缓存，缓存只能手动删：
   设置 → 其他 → 清除缓存；也可以长按书架里的书 → 删除缓存。
2. 侧边栏 → 缓存管理：只列出已经缓存过章节的书，并显示「已缓存 N/M 章」的进度。
   一章都没缓存的书不会出现在这里。
3. 缓存管理里每本书右边有两个按钮：
   继续缓存（三角形）= 从第一个没缓存的章节一直缓存到最后一章；
   停止缓存（方块）= 立刻停下这本书的缓存。顶部菜单「全部停止」可以一次停掉所有任务。
4. 正在缓存时通知栏会显示进度，点通知可回到缓存管理。

五、书源
1. 支持 3.0 格式书源：书源管理 → 右上角菜单 → 本地导入 / 网络导入，选 JSON 即可。
2. 书源失效是常态，搜不到就换源；建议定期更新自己的书源列表。
3. 书源管理里可以单选/多选书源做「校验」，批量筛掉失效的源。

六、老设备提示（Kindle 等 Android 4.4）
1. 阅读时全屏；调出菜单时状态栏和导航栏会出现，但阅读页尺寸不变，正文不会重新排版、不会闪。
2. 内存小的机器：书架别放太多书，别同时开其他应用，定期清缓存。
3. 启动后第一次进书架可能要等几秒，是在加载书源和书籍信息，之后会很快。
4. Kindle / Fire OS 请装「阅读Lite-1.0-Kindle.apk」（只签 v1 的包）。
   普通包在 Fire OS 上安装时，系统会弹「应用包访问权限帮助程序已停止」，那是系统安装服务解析不了
   带 v2 签名的包，不影响应用本身。

七、常见问题
1. 搜索没结果、一直转圈：多数是书源失效或网络问题，换个源试试。
2. 番茄直达报错：接口被官方改了，等更新。
3. 主题：只保留黑白两套配色，白天/夜间切换在阅读菜单里。
4. 本版没有朗读功能：朗读、朗读定时、朗读语速都已删除。
5. 换设备或重装前：设置 → 其他 → 备份，导出书源和书架数据。
