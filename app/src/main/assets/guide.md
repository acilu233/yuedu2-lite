使用说明

一、第一次使用
1. 先确认书源：侧边栏 → 书源管理，书源要处于启用状态（本版内置了番茄书源）。
2. 找书：书架页的搜索按钮 → 输入书名 → 在结果里挑一个来源 → 加入书架。
3. 本地书：书架页侧边栏 → 添加本地，可导入手机里的 txt 文件。

二、番茄直达（内置）
1. 搜索页右上角菜单 → 番茄直达。
2. 粘贴番茄小说的分享链接、分享文案或书籍 ID，也可以直接按书名搜；选中后加入书架即可阅读。
3. 番茄接口是官方私有接口，随时可能被改动。失效时请等新版本，或改用其他书源。

三、阅读操作
1. 点屏幕中间：调出阅读菜单（目录、进度、上一页/下一页、界面设置、更多设置）。
2. 点屏幕左/右两侧：翻页。也可以在「更多设置」里开启音量键翻页。
3. 长按正文：划线、复制、搜索、替换。
4. 阅读菜单 → 界面：字体、字号、行距、段距、左右边距、全屏等。
5. 阅读菜单 → 更多：翻页方式、自动翻页、屏幕常亮、缓存、备份等。

四、缓存（注意）
本版取消了自动清理缓存，缓存只能手动删：
设置 → 其他 → 清除缓存；也可以长按书架里的书 → 删除缓存。

五、书源
1. 支持 3.0 格式书源：书源管理 → 右上角菜单 → 本地导入 / 网络导入，选 JSON 即可。
2. 书源失效是常态，搜不到就换源；建议定期更新自己的书源列表。
3. 书源管理里可以单选/多选书源做「校验」，批量筛掉失效的源。

六、老设备提示（Kindle 等 Android 4.4）
1. 阅读时全屏；调出菜单时状态栏和导航栏会出现，但阅读页尺寸不变，正文不会重新排版、不会闪。
2. 内存小的机器：书架别放太多书，别同时开其他应用，定期清缓存。
3. 启动后第一次进书架可能要等几秒，是在加载书源和书籍信息，之后会很快。

七、常见问题
1. 搜索没结果、一直转圈：多数是书源失效或网络问题，换个源试试。
2. 番茄直达报错：接口被官方改了，等更新。
3. 主题：只保留黑白两套配色，白天/夜间切换在阅读菜单里。
4. 本版没有朗读功能：朗读、朗读定时、朗读语速都已删除，阅读菜单底部只有自动翻页、替换规则、夜间三个按钮。
5. 换设备或重装前：设置 → 其他 → 备份，导出书源和书架数据。
