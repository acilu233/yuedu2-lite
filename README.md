# 阅读 Lite（YueDuLite）

极致轻量的开源阅读器，专为老旧设备准备：Android 4.4（Kindle、老平板、老手机）也能顺畅看小说。
基于[阅读 2.0 / MyBookshelf](https://github.com/gedoor/MyBookshelf)精简改造，遵循 GPL-3.0 协议开源。

仓库地址：<https://github.com/acilu233/yuedu2-lite>

安装包约 10MB，无广告、无付费门槛、无推广内容；支持 3.0 格式书源，并内置番茄书源。

## 特点

- **轻**：去掉了朗读（TTS）、有声书、WebDAV、Web 服务、扫码、Wi-Fi 传书等用不到的功能，包体从 18MB+ 压到约 10MB。
- **快**：启动只加载必要内容，冷启动约 2~3 秒；书源、书籍信息在后台线程加载，不卡主线程。
- **老设备友好**：适配 Android 4.4（API 19），处理了老系统 TLS 1.2 握手、内存吃紧被杀后台等问题。
- **墨水屏优先**：只保留黑白两套配色，去掉界面动画和翻页动画，翻页无残影；白天/夜间在阅读菜单里切换。
- **阅读页稳**：阅读时全屏，菜单放在屏幕左右两侧（左：目录/调节/自动翻页/上一章，右：界面/设置/夜间/下一章），只是浮在正文上层——开关菜单都不会让正文重新排版、不会闪。
- **缓存管理**：侧边栏 → 缓存管理，只列已经缓存过章节的书并显示缓存进度，可以单本「继续缓存 / 停止缓存」。
- **书源**：支持 3.0 格式书源（JSON 直接导入），内置番茄书源。
- **番茄直达**：搜索页菜单 → 番茄直达，粘贴分享链接/文案/书籍 ID 或直接搜书名即可阅读。
- **干净**：移除了捐赠入口、公众号/QQ 群推广、付费门禁和所有广告代码。

## 本次更新（1.2）

- **修复「目录名存实亡」**：点目录里的章节跳不过去——低内存设备（或开发者选项里的"不保留活动"）上，打开目录时阅读页会被系统回收，原来靠内存事件传递的跳转就丢了；现在跳转目标会记录在进程内，阅读页重建后照样跳过去。
- **修复跳章节时卡死**：逐字排版时每个字都调用 `StaticLayout.getDesiredWidth`，一页几百个字在 4.4 老设备上要好几秒（会弹"阅读 Lite 无响应"）；改成 `measureText` 并去掉每字一个临时字符串，跳远处章节不再卡。

## 使用说明

应用内自带完整说明：**关于 → 使用说明**。这里只列最常用的几条：

1. 找书：书架页搜索按钮 → 输入书名 → 选一个来源 → 加入书架。
2. 阅读：点屏幕中间调出菜单——左侧是 目录、调节、自动翻页、上一章，右侧是 界面、设置、夜间模式、下一章；点左右两侧空白处翻页。
3. 界面：阅读菜单 → 界面，可调字体、字号、行距、段距、边距和全屏。
4. 缓存：本版取消了自动清理，只能在 设置 → 其他 → 清除缓存 手动删。
5. 缓存管理：侧边栏 → 缓存管理，看得到每本已缓存的书和进度，可继续或停止缓存。
6. 备份：设置 → 其他 → 备份，导出书源和书架数据。

## 已知问题 / 可能存在的问题

老设备上的取舍都要说清楚，以下是目前已知的：

1. **书源失效是常态**：所有内容都来自第三方书源，搜不到、加载慢、章节缺字大多是书源本身的问题，换源即可，本项目不提供、也不维护书源。
2. **番茄接口不稳定**：番茄直达走的是官方私有接口，随时可能被官方改动而失效；失效后需要等版本更新。
3. **只保证 4.4 及以上**：4.4 是真机调过的；新系统能正常使用，但没有针对全面屏手势、深色状态栏等做额外适配。
4. **低内存设备有上限**：像 210MB 内存的老 Kindle，超长章节或同时开多个应用时仍可能卡顿、被杀后台。
5. **阅读设置里的全屏开关**：关掉“隐藏状态栏/导航栏”后，4.4 上系统栏会浮在正文上方（这是为了让正文不重排做出的取舍），建议保持默认。
6. **只有黑白主题**：不提供自定义配色，只保留白天/夜间两套。
7. **没有朗读/有声书**：朗读、朗读定时、朗读语速、音频播放整块功能都已删除。
8. **不做跨设备同步**：Web 服务、WebDAV 都已移除，同步只能靠手动备份文件。
9. **Kindle 请用专用安装包**：Fire OS / Android 4.4 的系统安装服务解析不了带 v2 签名的包（会在装包时弹「应用包访问权限帮助程序已停止」，偶尔还把安装卡住），所以额外提供了只签 v1 的 `YueDuLite-1.2-Kindle.apk`；普通包 `YueDuLite-1.2.apk` 给现代系统用（Android 11+ 只接受带 v2 签名的包）。

## 构建

环境：JDK 11（不要用 17）、Android SDK（compileSdk 31、buildTools 30.0.3）。

```bash
cd MyBookshelf
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/YueDuLite_1.2.apk`

给 Kindle / Android 4.4 老设备出包时加一个参数，产物是只签 v1 的包（文件名带 `_kindle`）：

```bash
./gradlew :app:assembleRelease -PkindleSign
# → app/build/outputs/apk/release/YueDuLite_1.2_kindle.apk
```

两个包的区别只有签名方案：默认包 v1+v2（Android 11+ 要求），`-PkindleSign` 包只签 v1（Fire OS 4.4 的安装服务才不会崩）。签名证书是同一把，升级可以互相覆盖安装。

### 签名

- 仓库自带一份演示签名（`app/key.properties.jks`），clone 下来不做任何配置也能构建出可安装的包，仅供测试。
- 要发布自己的版本，把 `keystore.properties.example` 复制成 `keystore.properties` 并填入自己的密钥库信息（该文件已被 `.gitignore` 忽略，不会进仓库）：

```bash
keytool -genkeypair -keystore ../keys/yuedulite-release.jks -alias yuedulite \
        -keyalg RSA -keysize 2048 -validity 10950 -storetype PKCS12
```

**换签名后必须卸载旧版再安装**（Android 不允许签名不同的包覆盖安装），并且以后每个版本都要用同一把钥匙，否则用户无法升级。密钥库和口令请自行备份，丢了就再也签不出能覆盖安装的包。
